# Registro Ore Cantieri — versione personale senza account

Questa copia usa le Utility aggiornate ma lavora in modalità personale: non mostra l’accesso, non si collega a Supabase e non carica foto su Cloudflare.

## Dati e foto

- Rapportini, anagrafica, lista materiali, quadri e foto restano nel browser del dispositivo.
- Non c’è sincronizzazione automatica fra persone o dispositivi.
- Esporta il backup JSON per trasferire l’archivio. Il formato include le foto salvate localmente.
- Per inoltrare una foto usa **Condividi** nella galleria; se il browser non offre la condivisione diretta, la foto viene scaricata con il nome di cliente/cantiere.
- Le foto già presenti solo nel cloud non vengono scaricate automaticamente. Prima di passare a questa versione, esporta dall’app account o scarica le foto cloud che vuoi conservare localmente.

## Pubblicazione

Carica tutti i file di questa cartella nella radice del sito GitHub Pages principale. Mantieni gli stessi indirizzi e la stessa cartella per non separare i dati locali esistenti. I file sono stati preparati come copia locale distinta: la PWA account originale resta intatta nella cartella di revisione.

Per installarla su iPhone: apri il link in Safari, tocca **Condividi → Aggiungi alla schermata Home**.

La PWA TEST con account deve essere pubblicata a parte e usare un database/cache di prova isolati.
