INSTALLAZIONE PWA TEST SU iPHONE

1. Pubblica il contenuto di questa cartella nella cartella `test/` del repository GitHub Pages. Non sostituire la radice della PWA personale.
2. Apri in Safari: https://simonezussa-maker.github.io/gestioneorecantiere/test/
3. Tocca Condividi → Aggiungi alla schermata Home → Aggiungi.
4. Avvia l’icona Registro TEST e accedi con l’account di prova.

La versione TEST ha database, sessione e cache distinti dalla PWA personale.
