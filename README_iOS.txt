GUIDA PER INSTALLARE L'APP SU iPHONE / IPAD (iOS):

1. Carica tutti i file di questa cartella su un servizio di hosting web (es. GitHub Pages, Netlify, Vercel o un tuo spazio web con protocollo HTTPS).
2. Apri il link del sito web utilizzando il browser **Safari** sul tuo iPhone o iPad.
3. Tocca il pulsante **Condividi** (l'icona del quadrato con la freccia verso l'alto) nella barra inferiore di Safari.
4. Scorri il menu e seleziona **"Aggiungi alla schermata Home"**.
5. Conferma toccando **Aggiungi**.

Questa versione include ottimizzazioni avanzate per iOS:
- Rimozione totale del ritardo al tocco (300ms tap delay).
- Scorrimento inerziale fluido (momentum scrolling).
- Gestione corretta delle aree di sicurezza (Notch / Dynamic Island e barra inferiore di iOS).
- Transizioni fluide e accelerate via GPU.
- L'accesso richiede un account invitato; per il primo accesso serve una connessione Internet.
- L'editor Quadri usa lo schermo intero e rispetta le aree di sicurezza iPhone; resta da provare su Safari/iPhone reale.
